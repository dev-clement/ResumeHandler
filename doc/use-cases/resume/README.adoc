== Introduction
Before writing code, it is essential to map out exactly how a user interacts with the system. Therefore Use Case diagrams serve as the functional blueprint for the ResumeHandler application. They bridge the gap between abstract requirements and concrete implementation.

== Why create these diagrams?
The creation of these specific diagrams serves three primary purposes:

. Scope Definition: By identifying every button (like the "Close" or "+" buttons) and every action, we ensure that the development phase covers all UI/UX requirements.
. User Journey Mapping: They help visualize the workflow from the moment a user lands on the dashboard to the moment they delete or update a resume.
. Technical Contract: These diagrams inform our Sequence Diagrams and Backend API design, ensuring we have endpoints that match every functional need.

== Core Functional Modules (CRUD)

The ResumeManagement system is divided into four main functional pillars, documented in detail through Mermaid diagrams.

=== 1. Resume Listing (Read)
This is the entry point of the dashboard. It defines how the user perceives their existing data through a visual horizontal list.

👉 link:list-all-resume.md[View Listing Use Case]

Focus: Visualization and navigation.

Key Features: Horizontal scrolling, blurred previews for privacy, and quick-action triggers.

=== 2. Resume Creation (Create)
Describes the initialization of a new professional profile.

👉 link:create-new-resume.md[View Creation Use Case]

Focus: Data entry and workflow control.

Key Features: Section-by-section modification and explicit "Create" vs "Close" actions to manage state.

=== 3. Resume Modification (Update)
Handles changes to existing resumes, ensuring the user doesn't have to start from scratch.

👉 link:update-resume.md[View Update Use Case]

Focus: Consistency and data persistence.

Key Features: Pre-filled fields matching the existing data and contextual "Update" buttons.

=== 4. Resume Removal (Delete)
Manages the cleanup and life-cycle end of the documents.

👉 link:remove-resume.md[View Removal Use Case]

Focus: Efficiency and batch operations.

Key Features: Individual deletion for precision and "Remove All" for quick account resets.
